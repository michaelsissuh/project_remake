FLOW 1: STUDENT REGISTRATION & LOGIN FLOW
=====================================

graph TD

    R -->|Match| L
    
    N --> S[Student Dashboard]

FLOW 21: OTP EMAIL VERIFICATION FLOW (Complete)
=====================================

graph TD
    A[User Requests OTP] --> B{Reason for OTP}
    B -->|Student Forgot Password| C[User Provides Email]
    B -->|Visitor Forgot Password| C
    B -->|Email Verification| C
    C --> D[Backend: Validate Email Format]
    D -->|Invalid| E[Return Error: Invalid Email]
    E --> F[User Can Retry]
    D -->|Valid| G[Backend: Rate Limit Check]
    G -->|Too Recent| H[Return Error: Wait 60 Seconds]
    H --> F
    G -->|OK| I[Backend: Check User Exists]
    I -->|Not Found| J[Return Error: User Not Found]
    J --> F
    I -->|Found| K[Generate 6-Digit Random OTP]
    K --> L[Hash OTP with bcrypt]
    L --> M[Create Expiration: Current Time + 5 Minutes]
    M --> N[Save to email_otps Table]
    N --> O{Brevo API Call}
    O -->|Success| P[Email Sent to User]
    O -->|Failure| Q[Return Error: Email Failed]
    Q --> F
    P --> R[User Receives Email with OTP]
    R --> S[User Enters OTP Code]
    S --> T[Backend: Query email_otps Table]
    T -->|Not Found| U[Return Error: No OTP Found]
    U --> S
    T -->|Found| V[Check Expiration]
    V -->|Expired| W[Return Error: OTP Expired]
    W --> X[Optionally Allow: Send New OTP]
    X --> F
    V -->|Valid| Y[Check Attempt Count]
    Y -->|Max Attempts Exceeded| Z[Return Error: Too Many Attempts]
    Z --> X
    Y -->|Under Limit| AA[Compare User OTP with Stored Hash]
    AA -->|No Match| AB[Increment Attempt Count]
    AB --> AC[Return Error: Invalid OTP]
    AC --> S
    AA -->|Match| AD[Verify OTP as Used]
    AD --> AE[Allow Password Reset]
    AE --> AF[User Enters New Password]
    AF --> AG[Hash New Password]
    AG --> AH{Which User Type?}
    AH -->|Student| AI[Update students Table]
    AH -->|Visitor| AJ[Update visitors Table]
    AI --> AK[Mark OTP as Used/Delete]
    AJ --> AK
    AK --> AL[Return Success: Password Changed]
    AL --> AM[Redirect to Login]
