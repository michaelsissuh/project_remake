================================================================================
                    PROJECT API ENDPOINTS DOCUMENTATION

Base URL: http://localhost:5000/api

================================================================================
                            AUTHENTICATION ROUTES
                              /api/auth/*
================================================================================

STUDENT AUTHENTICATION:
  POST /auth/student/signup
    - Student registration with name, email, student ID, and password
    - Creates new student account

  POST /auth/student/login
    - Student login with student ID and password
    - Returns authentication token

  POST /auth/student/forgot-password
    - Request OTP for password reset
    - Sends OTP to registered email

  POST /auth/student/reset-password
    - Reset student password using email, OTP, and new password
    - Verifies OTP before updating password

ADMIN AUTHENTICATION:
  POST /auth/admin/login
    - Admin login with username and password
    - Returns authentication token

HOSTEL AUTHENTICATION:
  POST /auth/hostel/login
    - Hostel manager login
    - Returns authentication token

VISITOR AUTHENTICATION:
  POST /auth/visitor/signup
    - Visitor registration
    - Creates new visitor account

  POST /auth/visitor/login
    - Visitor login
    - Returns authentication token

  POST /auth/visitor/forgot-password
    - Request OTP for visitor password reset
    - Sends OTP to registered email

  POST /auth/visitor/reset-password
    - Reset visitor password using email, OTP, and new password
    - Verifies OTP before updating password

OTP MANAGEMENT:
  POST /auth/request-otp
    - General OTP request endpoint
    - Initiates OTP flow

  POST /auth/verify-otp
    - Verify OTP code
    - Validates OTP and completes verification

USER INFO:
  GET /auth/me
    - Get current authenticated user information
    - Returns user role, ID, and other details


================================================================================
                        APPOINTMENTS ROUTES
                       /api/appointments/*
================================================================================

STUDENT APPOINTMENTS:
  POST /appointments/student
    - Student creates appointment request with dean
    - Protected (Student only)

  GET /appointments/student/my
    - Student fetches all their appointments
    - Protected (Student only)
    - Returns list of student's appointments with status

ADMIN APPOINTMENTS:
  GET /appointments/admin
    - Admin fetches all appointment requests
    - Protected (Admin only)
    - Returns list of all appointments

  PUT /appointments/admin/:id
    - Admin updates appointment status (approve/decline)
    - Protected (Admin only)
    - Status: approved, declined, rescheduled

                        /api/notifications/*
================================================================================

NOTIFICATION MANAGEMENT:
  GET /notifications/
    - Fetch user notifications
    - Returns list of notifications

================================================================================
                          AUTHENTICATION NOTES
================================================================================

- Authentication tokens are JWT-based with 1-day expiration
- Tokens are sent as HttpOnly cookies for security
- Protected routes require valid token and correct role
- Roles: student, admin, hostel, visitor
- All authentication errors return 400 or 401 status codes


================================================================================
                            FILE UPLOADS
================================================================================

Supported File Types:
  - PDF (application/pdf)
  - JPG (image/jpeg)
  - JPEG (image/jpeg)
  - PNG (image/png)

Upload Endpoints:
  - POST /hostels/complaints (Hostel complaints with attachments)
  - POST /visitor/bookings (Visitor bookings with documents)

Upload Location: /backend/uploads/
File naming: {timestamp}-{sanitized_filename}


================================================================================
                            REQUEST/RESPONSE
================================================================================

Request Headers:
  - Content-Type: application/json
  - Authorization: (Included automatically via cookie)

Common Status Codes:
  - 200: Success
  - 201: Created
  - 400: Bad Request
  - 401: Unauthorized
  - 403: Forbidden
  - 404: Not Found
  - 500: Server Error


================================================================================
                         MIDDLEWARE PROTECTION
================================================================================

Route Protection:
  - protectStudent: Only authenticated students
  - protectAdmin: Only authenticated admins
  - protectHostel: Only authenticated hostel managers
  - protectVisitor: Only authenticated visitors
  - authMiddleware: General authentication check


================================================================================
                       API ENVIRONMENT VARIABLES
================================================================================

Required Environment Variables:
  - JWT_SECRET: Secret key for JWT token signing
  - COHERE_API_KEY: API key for Cohere AI chat functionality
  - NODE_ENV: development/production
  - PORT: Server port (default: 5000)
  - ALLOWED_ORIGINS: CORS allowed origins (comma-separated)

Database:
  - Database connection configured in backend/models/db.js
  - MySQL/MariaDB database required
